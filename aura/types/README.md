# Type plugins

One module per supported type, e.g.:

- `brain_gemini.py` → `arpa.brain.gemini`
- `skills_bundle.py` → `arpa.skills.bundle`
- `guardrails_ruleset.py` → `arpa.guardrails.ruleset`
- `drive_goal.py` → `arpa.drive.goal`

Community types ship as separate packages (`aura-types-*`).

See [spec/type-plugin.contract.md](../../spec/type-plugin.contract.md).
