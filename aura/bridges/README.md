# Bridges

Optional integrations to ARPA stack projects.

| Module | Project | Role |
|---|---|---|
| `liveid` | Live ID | Manifest loader, session registry, UBH |
| `legacy` | [Legacy Protocol](https://github.com/arpahls/legacy-protocol) | Continuity export |
| `rooms` | [Rooms](https://github.com/arpahls/rooms) | Environment context |
| `skills` | Skills type plugins | Capability execution and enriched audit |
| `synapuls` | Synapuls | Surface security |
| `mnemolink` | MnemoLink | Memory policy |
